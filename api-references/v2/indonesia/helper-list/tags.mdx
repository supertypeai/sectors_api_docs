---
title: IDX News & Filings Tags List API
openapi: GET /v2/tags/
sidebarTitle: News Tags
description: Browse the tags used to classify IDX news and insider filings, to build topic-based feeds and alerts on Indonesian stocks.
---

Tags are returned as an alphabetically sorted array. Use these values as inputs to the `tags` parameter.

**Used by:** [News Articles](https://docs.sectors.app/api-references/v2/indonesia/news/news), [Company Filings](https://docs.sectors.app/api-references/v2/indonesia/news/filings)

<Info>Costs 1 API credit.</Info>
