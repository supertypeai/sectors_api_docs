---
title: Most Traded IDX Stocks API by Volume
openapi: GET /v2/most-traded/
sidebarTitle: Most Traded Stocks
description: See the most traded IDX stocks by volume day by day, to find the most liquid Indonesian names market-wide or within a single subsector.
---

Results are keyed by date.

<Note>Date range: defaults to last 30 days. Max window 90 days; wider ranges are clamped to the most recent 90 days ending at `end`. Future `end` dates return 400.</Note>

<Info>Costs 2 API credits.</Info>
