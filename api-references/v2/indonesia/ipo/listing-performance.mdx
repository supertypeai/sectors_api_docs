---
title: "IDX IPO Performance API: Returns Since Listing"
openapi: GET /v2/listing-performance/{symbol}/
sidebarTitle: Company IPO & Listing Performance
description: Measure how IDX IPOs performed after listing, and compare recent Indonesian listings with earlier ones, for IPO research and post-listing return analysis.
---

Price changes are measured from the listing date over 7, 30, 90, and 365-day windows.

<Note>Listing performance data is only available for tickers listed **after May 2005**.</Note>

<Note>IDX symbol: 4 letters, optionally followed by `.jk` (case-insensitive). E.g. `GOTO`, `BREN`, `BUKA`.</Note>

<Info>Costs 1 API credit.</Info>
