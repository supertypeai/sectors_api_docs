---
title: Mining Company Sales by Country API
openapi: GET /v2/mining/sales-destination/{slug}/
sidebarTitle: Company Sales Destinations
description: Break down an Indonesian mining company's sales by country to see how much of its revenue depends on a few buyer countries, year by year.
---

If no year is specified, the latest available year is used.

`revenue_usd` is in base USD. Volume unit is specified per country entry in `unit` (e.g., `Mt`).

<Info>Costs 1 API credit.</Info>
