---
title: Global Commodity Production & Reserves API
openapi: GET /v2/mining/global-commodity/
sidebarTitle: Global Commodity Data
description: Compare Indonesia's coal, nickel, gold, copper and bauxite production and reserves with other producing countries in global commodity data.
---

At least one of `commodity_type` or `country` must be provided.

<Note>Available `commodity_type` values: `Coal`, `Gold`, `Nickel`, `Copper`, `Bauxite`.</Note>

<Info>Costs 1 API credit.</Info>
