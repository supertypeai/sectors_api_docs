---
title: Indonesia Mining Licenses API (IUP/IUPK)
openapi: GET /v2/mining/licenses/
sidebarTitle: Mining Licenses
description: Check when an Indonesian IUP or IUPK mining license expires and whether it is Clear & Clean, for supplier due diligence and renewal-risk tracking.
---

Licenses are sourced from the ESDM Minerba portal.

<Note>Top `commodity_type` values: `Coal`, `Nickel`, `Non-Metallic Mineral`, `Sand/Stone/Gravel`, `Limestone`, `Gold`, `Tin`, `Iron`, `Bauxite`, `Clay`, `Copper`.</Note>

Prefix `order_by` with `-` for descending order. Default sort: `license_expiry_date` (soonest expiring first).

<Info>Costs 1 API credit.</Info>
