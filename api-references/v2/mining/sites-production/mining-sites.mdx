---
title: Indonesia Mining Sites API (Coal, Nickel)
openapi: GET /v2/mining/sites/
sidebarTitle: Mining Sites
description: Find Indonesian coal, nickel, gold and copper mining sites by province, owner and output, and see which operations produce the most.
---

<Note>Available `commodity_type` values: `Coal`, `Gold`, `Nickel`, `Copper`.</Note>

Prefix `order_by` with `-` for descending order (e.g. `-production_volume`).

<Info>Costs 1 API credit.</Info>
