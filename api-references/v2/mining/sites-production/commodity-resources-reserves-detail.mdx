---
title: Indonesia Resources & Reserves API by Province
openapi: GET /v2/mining/resources-reserves/{province}/
sidebarTitle: Resources & Reserves Detail
description: Size an Indonesian province's mineral resources and reserves over time, from exploration targets down to reserves, for each commodity.
---

Data is nested by year, then by commodity. Each commodity entry contains the full breakdown: `exploration_target`, `total_inventory`, `resources`, `reserves`, and `unit`.

<Note>Available `commodity_type` values: `Coal`, `Gold`, `Silver`, `Copper`, `Nickel`, `Cobalt`, `Tin`.</Note>

<Info>Costs 1 API credit.</Info>
