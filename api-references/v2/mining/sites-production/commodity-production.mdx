---
title: Indonesia Coal & Nickel Production API
openapi: GET /v2/mining/total-production/
sidebarTitle: Total Commodity Production
description: Get Indonesia's total national production of coal, nickel, gold or copper by year, with year-over-year change. JSON REST API.
---

Returns total national production for a commodity across all years, including year-over-year percentage change. Results are ordered by year descending.

<Note>Available `commodity_type` values: `Coal`, `Nickel`, `Gold`, `Copper`.</Note>

<Info>Costs 1 API credit.</Info>
