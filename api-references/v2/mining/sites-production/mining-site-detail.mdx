---
title: Indonesia Mining Site Detail API
openapi: GET /v2/mining/sites/{slug}/
sidebarTitle: Mining Site Detail
description: "Get full details for one Indonesian mining site: resources and reserves, plus location with latitude and longitude. JSON REST API."
---

Returns full details for a single mining site by its slug, including parsed resources/reserves and location (with latitude and longitude).

Use [Mining Sites](https://docs.sectors.app/api-references/v2/mining/sites-production/mining-sites) to discover site slugs.

<Info>Costs 1 API credit.</Info>
