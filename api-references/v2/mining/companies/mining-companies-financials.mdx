---
title: Mining Company Financials API (Indonesia)
openapi: GET /v2/mining/companies/financials/{slug}/
sidebarTitle: Mining Company Financials
description: Get annual assets, revenue and profit, with breakdowns, for Indonesian mining companies. Values in USD millions, latest year by default.
---

Returns annual financial records (assets, revenue, profit with breakdowns) for a mining company. All monetary values are in USD millions. Defaults to the latest available year.

<Info>Costs 1 API credit.</Info>
