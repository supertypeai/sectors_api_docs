---
title: Mining Company Financials API (Indonesia)
openapi: GET /v2/mining/companies/financials/{slug}/
sidebarTitle: Mining Company Financials
description: Compare annual results of Indonesian mining companies side by side in US dollars, so coal, nickel and gold miners sit on one currency basis.
---

All monetary values are in USD millions. When `year` is omitted, data for the latest available year is returned.

<Info>Costs 1 API credit.</Info>
