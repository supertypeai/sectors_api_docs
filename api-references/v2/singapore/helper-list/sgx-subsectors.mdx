title: SGX Subsectors List API
openapi: GET /v2/sgx/subsectors/
sidebarTitle: SGX Subsectors
description: List every SGX sector and subsector pair as API-ready slugs, for filtering Singapore-listed companies in the SGX screener. JSON REST API.
---

Returns all available SGX sector/subsector pairs as kebab-case slugs. Use these values as inputs to `sector` and `sub_sector` parameters.

**Used by:** [SGX Companies](https://docs.sectors.app/api-references/v2/singapore/screener/sgx-companies)

<Info>Costs 1 API credit.</Info>
