---
title: SGX News Tags List API
openapi: GET /v2/sgx/tags/
sidebarTitle: SGX News Tags
description: List all tags used across Singapore Exchange (SGX) news articles, to filter the SGX News endpoint by topic. JSON REST API.
---

Returns the complete list of distinct tag slugs found across all SGX news articles. Use these values with the `tags` parameter of the [SGX News](https://docs.sectors.app/api-references/v2/singapore/news/sgx-news) endpoint.

<Info>Costs 1 API credit.</Info>
