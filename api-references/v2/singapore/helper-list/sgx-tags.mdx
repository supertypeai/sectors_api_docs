---
title: SGX News Tags List API
openapi: GET /v2/sgx/tags/
sidebarTitle: SGX News Tags
description: Discover the topics SGX news is tagged with, so readers and apps can follow themes across Singapore company news rather than individual tickers.
---

Use the returned tag slugs with the `tags` parameter of the [SGX News](https://docs.sectors.app/api-references/v2/singapore/news/sgx-news) endpoint.

<Info>Costs 1 API credit.</Info>
